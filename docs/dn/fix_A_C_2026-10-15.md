## 採用的 rate function 與參數

運動 DN 為 graph 的 `turn | forward`（真實圖為 DNa01、DNa02、DNp09 各左右，共六個）：

```text
r_i(v) = softplus(β v) / β  （運動 DN）
r_i(v) = relu(v)            （其他中央神經元）
β = motor_rate_beta = 10.0
```

實作用 `F.softplus(v, beta=10.0)`，其內部已包含除以 β。這是**維持負電位梯度的工程選擇，不是生物學測量**。`r(0)=ln(2)/10≈0.0693147`，左右相同率在結構轉向中相消，前進輸出可略偏移。未改 bias 初始化，沒有採 B 或 D，沒有新增輔助動作 loss。

兩個 rate 的 Lipschitz 常數都 ≤1，因此原有 `ρ(|W|)=0.9` 的初始化規則仍適用；`τ>2dt` 使 Euler ratio 在 (0,1/2)。在適當正加權無窮範數中，若 `|W|q≤cq`、c<1，差分上界為 `max_i(1-r_i+r_i c)<1`。softplus 靜息項會改固定點，不影響此差分界。原本收縮測試、Dale 號誌／不可創邊、dense／CSR 前向與梯度、cached／uncached、`forward == forward_code ∘ sense` 均通過。非 DN 的 rate 與積分公式不變；有 DN 回饋時，其他神經元的軌跡不要求與舊版相同。

活動正則是非 DN 平方率平均；只排除直接懲罰，DN 仍可能透過對非 DN 的回饋接收到間接梯度。沒有因果消融，**不推論活動正則就是原沉默的成因**。

## 診斷門檻與計畫問題

計畫原本只要求 DN 的正活性比例；softplus 靜息值會讓此條件幾乎自動成立。因此保留嚴格 `rate>0` 原始比例，另加 `rate>1e-3` 的有效比例，並仍以換眼反應、動作梯度與 BC 誤差共同判斷。這個有效門檻也是工程診斷值，並非生物量測。

生物圖 gate 要求至少 4 DN 有 ≥10% 有效步數、中央群組梯度 >1e-6、各值有限、非全部沉默；有視覺輸入的變體另要求換眼角速度差中位數 ≥0.05。O 的視覺被模型刻意關閉，因此不套這一條；GRU 略過生物 DN gate。BC 階段另要求角速度 MAE 比固定零輸出至少低 20%。

計畫把嚴格的換眼門檻放在預訓練階段，但預訓練讀出沒有動作目標，本次反事實探針也未達此門檻；它可能在進 BC 前就攔下整個鏈。**本次沒有放寬門檻、調參追過門檻或擴大成 B／D 方案。** 負電位梯度恢復的探針未顯示 A＋C 在機制上明顯不可行，但控制驗收確實未通過，須由後續經授權的訓練判斷；不能把此版本記為整體問題已解決。

## 未解決風險

1. softplus 的靜息正率與小幅前進偏移不是感覺控制證據；smoke 的換眼反應仍比 0.05 門檻小約兩百多倍，中斷 V checkpoint 的中位數仍為 0。沒有完成控制能力驗收。
2. 上游 raw_alpha 梯度恢復但很小；中央群組梯度可能主要由 bias 貢獻，未證明後續最佳化有效。若把 1e-6 解讀為每一個 core 參數群都必須達到，本次 raw_alpha／raw_tau 也沒有達標。
3. C 僅排除直接活動懲罰；預訓練 decoder 的梯度、間接回饋、長序列及訓練後譜半徑可能仍影響 DN。活動正則致死的因果推測未驗證。
