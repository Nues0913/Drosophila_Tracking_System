# WP3a：子圖 v2（Issue #134）

選定 sweep a，產物在 [`data/subgraphs/v2_main/`](../../data/subgraphs/v2_main/)，萃取設定為 [`v2_main.yaml`](../../configs/v2/extraction/v2_main.yaml)。計劃基準為 `4304571`。

## 規則與可重現性

- `edge_rule` 預設 `single_edge`，沿用 `min_synapses`；`type_sum` 的預設 `type_min_synapses=50`、`edge_min_synapses=10`。先按單邊門檻篩選，再對全腦所有有 type 的神經元累加 pre-type → post-type；型別總和不限 superclass、NT 或排除清單。合格邊同時用於 reach、誘導子圖、度數修剪與補救。
- 主萃取維持 bounded reach 交集、全腦型別 NT 多數決、NT drop、固定點修剪。`wind_downstream_hops` 預設跟隨 `downstream_hops`；風 seed 強制取 publisher `rootSide`，不明側別排除；`GROUP_WIND=32` 同時用於 group/input mask。
- `coverage_repair` 預設 false；`coverage_min=0.40`、`repair_max_hops=downstream_hops+2`。必要 DN 按 bodyId 排序；候選按突觸數降序、bodyId 升序；多源 BFS 的 seed 與鄰居按 bodyId 排序。候選、路徑全程受 anatomical/type/NT/no-KC/side 排除限制。到門檻立即停止；新增節點 protected，固定點修剪後仍須位於 seed→DN 路徑。
- 分支群體沿用各自的 bounded hop；僅實際補救路徑可額外標記來源分支，並在 manifest 記錄完整 bodyId 路徑。沒有將整個弱連通分量都標成各模態。
- `required_seed_types` 預設為 `null`，要求每個指定的型別至少保留一顆。給定清單時，只有清單內的型別必須各保留至少一顆。`required_seed_groups` 可加上群組條件，每組正規表示式至少要完整匹配一個已保留的 seed 型別。
- 覆蓋率分母與 `brain_input_synapses` 掃全部 raw weight，包含未標 type、範圍外、低門檻、NT 不明的突觸前輸入；`subgraph_input_synapses` 為輸出合格邊的 fan-in。兩陣列 float32 `[N]`，`protected` uint8 `[N]`；pre/post 維持 v1 的 node index。
- v2 的六個必要檔案採確定性輸出。既有三份 v1 設定重跑後的圖檔與診斷檔逐位元組一致。`manifest.json` 唯一變動欄位是記錄萃取器版本的 `extractor_source_sha256.graph.py`。
- 萃取失敗仍保留 sweep 診斷產物、manifest 與 coverage.md，CLI exit 1；覆蓋率候選耗盡也保留全部 DN 的最終數字，沒有將失敗產物當成正式圖。

### 重跑方式

在 repo 根目錄啟用專案的 Python 環境。讀取大型 edge 表時使用 `prlimit` 設定 6 GiB 上限。

```bash
PYTHONPATH=python OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 prlimit --as=6442450944 python -m connectome_extract extract --config configs/v2/extraction/v2_main.yaml < /dev/null
PYTHONPATH=python OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 prlimit --as=6442450944 python scripts/v2/verify_subgraph_v2.py --graph-dir data/subgraphs/v2_main --output runs/wp3a-seed-guard/verify-v2-main.json < /dev/null
PYTHONPATH=python python -m pytest -q python/tests < /dev/null
ruff check python scripts < /dev/null
ruff format --check python scripts < /dev/null
```

重跑歷史 sweep 時，將設定換成 `sweep_<代號>.yaml`，並將驗證目錄換成 `data/subgraphs/v2_sweep_<代號>/`。四份設定均已包含最終的 branch hop，預期 exit code 為 1。
